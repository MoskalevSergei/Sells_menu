# Sells_menu — инструкции для Codex

Проект — HTML-дашборд продаж нового и сезонного меню. Общайся с владельцем на русском, объясняй изменения простыми словами. Утверждённые расчёты описаны в `docs/BUSINESS_RULES.md`.

## Работа с кодом

- Редактируй `src/engine.js`, `src/app.js`, `src/template.html`; `index.html` собирается из них командой `npm run build`.
- Не переноси приложение на React, сервер или облачную базу без такого задания. Итог должен оставаться одним самодостаточным HTML с локальной загрузкой Excel.
- Для изменений расчётов используй математические контрольные примеры из `tests/`. Согласованные формулы не меняй как побочный эффект правки интерфейса.
- При порученном изменении методики обновляй код, относящиеся к нему проверки и описание правил.
- После правок исходников запускай `npm run check`. Локальные тесты используют искусственные данные и не обращаются к рабочим системам; выполняй их без дополнительных согласований.
- Если проверяется внешний вид, используй доступный браузер. Проверки генерации HTML не называй визуальной проверкой в браузере.
- Приведи `index.html` в соответствие с исходниками перед завершением. Указывай, что изменилось и какие проверки прошли.

## Данные и зависимости

- Репозиторий содержит только искусственные данные. Рабочие Excel, CSV, JSON, скриншоты и HTML, сохранённый с реальными данными, не добавляй в Git.
- `index.html` в репозитории должен быть собран командой `npm run build` из `scripts/demo.cjs`. Кнопка «Сохранить с данными» создаёт отдельный рабочий файл пользователя, а не замену публичному `index.html`.
- Реальные файлы загружаются через браузер. Сохранение и расчёты выполняются локально; не добавляй передачу данных на сервер, аналитику или внешние CDN.
- Node.js 20+ и Python 3 — инструменты разработки. В браузере они не нужны. Внешних npm-зависимостей нет; JSZip 3.10.1 лежит в `vendor/` с лицензией.
- Обычный запуск: открыть `index.html`. Локальный сервер: `npm start`. Подготовка среды: `bash scripts/codex-setup.sh`.

## Основные ограничения интерфейса

- Тип меню: «Все», «Новое», «Сезонное»; признак 0 — сезонное.
- Количество заказов не выводить в таблицах, подсказках и CSV. Обозначение «СКП на 100 заказов» допустимо.
- Общие фильтры действуют во всех вкладках; Ресторан рядом с Каналом, Группа рядом с Блюдом.
- Новые Excel должны содержать «Рестораны_Блюдо» (Код, Ресторан) и коды СПР. Оценивай только пары списка, сопоставленные со СПР по коду; проверяй наличие всех кодов СПР. Продажи вне списка сохраняй как обычные продажи соответствующих групп, включая историю до общей даты запуска.
- Все строки доступны через прокрутку. Не вводить лимит 25 строк.
- Первый столбец выравнивается влево, остальные ячейки и заголовки — по центру.
- Пустая ячейка обозначает отсутствие ассортимента или базы; ноль — известный ассортимент без продаж за период. Не выводить «Не продаётся».
- Подписывать отклонение как +20%, а не 120%. Охват частичного сравнения должен оставаться видимым.

Публикация и изменение доступа к репозиторию не входят в обычную локальную правку проекта; выполняй их только по прямому поручению владельца.
