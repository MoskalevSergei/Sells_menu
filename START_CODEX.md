Прочитай AGENTS.md и README.md. Это проект HTML-дашборда продаж нового и сезонного меню. Расчёты и требования из docs/BUSINESS_RULES.md уже согласованы.

Проверь, что проект готов к дальнейшей работе:

1. Запусти npm run check. Если есть проблема запуска или переносимости, исправь её и повтори затронутые проверки.
2. Убедись, что index.html открывается как самостоятельный файл, загружает Excel с «Меню_Продажи» в имени и сохраняет HTML с текущими данными. Для импорта используй искусственный пример, создаваемый npm run example. Если доступен браузер, проверь вкладки и фильтры в нём.
3. Проверь, что в репозитории и собранном index.html находятся только демонстрационные данные.
4. Сохрани принятую методику: СКП по объединению подходящей базы, отдельные даты запуска, рейтинг по общей части ассортимента с весами остальной сети, учёт только действующих каналов, видимый охват сравнения.
5. В конце кратко напиши по-русски, какие файлы отвечают за расчёты и интерфейс, что проверено, что исправлено и готов ли проект к следующим заданиям.

Существенных изменений оформления и расчётов на этом шаге не требуется. Рабочие данные в репозиторий не добавляй.
